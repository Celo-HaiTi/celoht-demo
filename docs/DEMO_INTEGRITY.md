# Demo integrity policy

This repository is an investor and grant-reviewer demo for CeloHT. It is not the live CeloHT production product, and it does not connect to real wallets, funds, or on-chain transactions.

Every simulated feature in this repo is labeled in context.

## Simulated areas

- Wallet connection: a fake address and short delay are used to simulate connection; no real Valora, MiniPay, or WalletConnect session is opened.
- Donation flow: a generated hash is clearly labeled as simulated and no real USDm or CELO is moved.
- Dashboard numbers: illustrative metrics are presented as demo values, not live production status.
- Maps and agent data: illustrative figures and points are not a live operational map.
- Ecosystem and partner references: described as ecosystem context or prospective relationships, not formal partner claims.

## Required presentation rule

When this demo is shown to partners, investors, or grant reviewers, the presenter should explicitly state that the experience is a simulated product preview rather than a live deployment.
